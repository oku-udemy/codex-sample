# E2E作業ガイド

ルート`AGENTS.md`に加えて、`e2e`以下では本書を適用します。

## 方針

Playwright E2EはFrontendとBackendを接続した主要な利用者導線と、ブラウザーでしか確認できない境界を検証します。コンポーネントやAPI単体で十分な分岐を重複して網羅せず、重要な正常系と代表的な回復不能エラーへ絞ります。

- ロール、ラベル、表示文言など利用者が認識できる方法で要素を特定します。
- 固定待機を使わず、Playwrightの自動待機とweb-first assertionを使います。
- 各テストは独立させ、時刻などを使って必要なデータを一意にします。
- 外部サービスへ接続しません。エラー再現には`page.route`などローカルな制御を使います。
- 失敗調査ではHTML reportとtraceを参照します。生成物はコミットしません。

実行はルートから`npm run test:e2e`です。主要導線、API接続、アクセシビリティ上重要な操作、レスポンシブ挙動を変えた場合にテストを更新します。詳細は`e2e/docs/`を参照します。
