# 業務要件原本の管理

案件ごとに`_template/`をコピーし、英数字とハイフンによる短いディレクトリ名を付けます。

```text
business/<案件名>/
  README.md
  source/       # 受領したWord／Excel原本
  extracted/    # 原本を正規化したMarkdown
```

`source/`のファイルは内容、ファイル名、シート構成を変更しません。差替え版を受領した場合は旧版を上書きせず、版または受領日が分かる名前で併存させます。秘密情報や個人情報を含む場合は、リポジトリへ保存する前に取扱方針を確認します。

抽出文書は逐語的な複製を目的とせず、見出し、表、業務ルール、画面項目、未決事項を検索可能な形へ正規化します。推測は事実として補わず、`未決事項`または`抽出上の注意`へ記録します。
