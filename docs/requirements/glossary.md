# 用語集

| 用語         | 定義                                                       | 使用上の注意                         |
| ------------ | ---------------------------------------------------------- | ------------------------------------ |
| Todo         | 利用者が登録する作業項目。`id`、`title`、`completed`を持つ | UI上の表記は「Todo」に統一する       |
| 完了         | Todoの`completed`が`true`である状態                        | 削除とは異なる                       |
| 業務原本     | 利用者から受領したWord／Excelファイル                      | `source/`へ不変保存する              |
| 抽出文書     | 業務原本を検索・差分確認しやすいMarkdownへ正規化したもの   | 原本への参照情報と抽出上の注意を持つ |
| システム要件 | 実装とテストの基準になる、確認済みの要件                   | 一意な要件IDを持つ                   |
| Frontend     | ブラウザーで動作するReactアプリ                            | `apps/frontend/`を指す               |
| Backend      | Todo HTTP APIを提供するExpressアプリ                       | `apps/backend/`を指す                |
| E2E          | 実ブラウザーからFrontendとBackendを接続して行う試験        | Playwrightで実行する                 |
| 現行仕様     | 現在のコードと一致し、利用可能な動作                       | 改善候補や提案と区別する             |
| ADR          | 重要なアーキテクチャ判断と理由を残す記録                   | `docs/architecture/adr/`へ置く       |
