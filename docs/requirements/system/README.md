# システム要件

案件ごとに1つのMarkdownを置き、業務要件を実装と検証に使える形へ定義します。新規文書は`plugins/dev-workflow/skills/requirements-definition/assets/system-requirements-template.md`を基準にしてください。

- ファイル名は案件ディレクトリと対応する短い`kebab-case`にします。
- 要件IDは一度公開したら再採番しません。
- 確定後に意味や範囲を変える場合は、根拠、影響、変更履歴を残します。
- 原本の出典と未解決事項を追跡できる状態にします。

このTodoサンプルの現行要件は`todo-sample.md`です。
